Prerequisites
Python 3.10 or newer.
Read-only exports of an Entra tenant (the bundled PowerShell collector can produce them), or the bundled demo tenants.
SafetyNotes
Runs a local Python CLI; review before installing. It only reads local JSON export files and writes reports to a folder you choose.
It never writes to a Microsoft Entra tenant. The optional PowerShell collector makes read-only Microsoft Graph GET requests with the read scopes you grant.
PrivacyNotes
Reads tenant export files (users, groups, roles, policies, optional sign-in logs) from local disk; reports stay on your machine.
No telemetry, no accounts, and no calls to any third-party service. The collector talks only to Microsoft Graph using your own sign-in.

EffectivePasskey
EffectivePasskey is a free, MIT-licensed skill and CLI for Microsoft Entra ID admins rolling out passkeys. Entra passkey profiles combine as a union while Conditional Access combines as an intersection, so the policy a user actually gets is hard to see in the portal. EffectivePasskey computes it per user from read-only exports and explains the result.

What it checks
Each user's effective passkey policy after overlapping profiles and Conditional Access authentication strengths.
Admins whose passkey rules are weakened by a broader profile.
Who will be blocked when SMS and voice sign-in are retired.
Temporary Access Pass bootstrap paths, tamperable groups, and admin attack paths.
A remediation simulator that previews the effect of a fix before you apply it in the tenant.
